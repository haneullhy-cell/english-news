# 네이버 블로그 자동 발행 (5 프롬프트)

출처: 바이브 메이커 「네이버 블로그 자동 발행」 무료 자료 (docs.vibemake.kr).
업로드는 uplika MCP 커넥터(`https://api.uplika.com/mcp`)로 한다. 이 저장소의 `.mcp.json`에 등록돼 있다.

## 0. 연결 확인 (처음 한 번)

uplika 도구(연결된 계정 조회 · 발행 기록 조회 · 글 발행)가 보이는지 확인하고,
연결된 네이버 블로그와 카테고리 목록을 조회해 사용자에게 보여준다.

- uplika 도구가 없으면: 사용자에게 아래 준비가 필요하다고 알린다. 대신 해줄 수 없는 단계다.
  1. uplika.com 가입 → 연결 → 새 연결 → Naver Blog (베타 · 확장 필요)
  2. 네이버에 로그인된 컴퓨터 크롬에 확장 「uplika 업로드 도우미」 설치
  3. 채널 카드에 「정상」 · 「확장 켜짐」 확인
  4. claude.ai 설정 → 커넥터 → 커스텀 커넥터 추가 → 이름 `uplika`, 주소 `https://api.uplika.com/mcp` → 승인 화면에서 「허용」
     (Claude Code에서는 `/mcp` 로 uplika 인증)

## 1. 기획서

사용자가 준 링크나 메모를 읽고 기획서 한 장으로 정리한다.
- 누구에게 쓰는 글인가 (문장 길이 · 예시가 정해짐)
- 무슨 문제를 풀어주나 (없으면 일기가 됨)
- 어떤 순서로 풀까 (그대로 소제목이 됨)
- 제목 후보 3개

## 2. 메인 키워드

기획서 주제를 1~2단어로 줄인 메인 키워드 후보 3개. 제목이 아니라 검색 입구라 넓게 잡는다.

## 3. 연관 키워드

메인 키워드마다 네이버 자동완성을 조회한다:

```
https://ac.search.naver.com/nx/ac?q=<메인키워드>&st=100&r_format=json
```

- 돌아온 목록에서 글이 실제로 답해주는 것만 3개 골라 기획서 맨 위에 「최종 키워드」로 적는다.
- 아무것도 안 돌아오면 한 단어 줄여서 다시 조회한다 (빈 목록 = 아무도 안 치는 말).
- 주소를 못 열면 사용자에게 네이버 검색창 자동완성 목록을 붙여넣어 달라고 한다.

## 4. 글쓰기

기획서와 최종 키워드 3개로 쓴다.
- 제목과 첫 문단 첫 줄에 키워드
- 본문 1,500자 이상, 소제목 3~4개는 `## `
- 키워드는 전체에서 3~5번만 (열 번 넘게 반복하면 저품질)
- 사진 자리는 `[사진: 무슨 사진]` 으로 한 줄에 하나씩
- 사용자가 자기 글 링크를 주면 그 말투를 따른다
- 마지막에 태그 12개 (그 이상 금지)

## 5. 업로드 (uplika)

- 카테고리: 사용자가 지정한 이름. 모르면 카테고리 목록을 먼저 보여준다.
- 본문은 쓴 구조 그대로 넘긴다. 블로그 폼으로 다시 배치하지 않고 `##` 같은 기호도 지우지 않는다.
  - `## ` 줄 → 소제목, `> ` 줄 → 인용구, `---` 줄 → 구분선, `![사진](media:아이디)` 줄 → 사진
- 사진: 사용자가 올린 사진(업로드 링크 발급) 또는 저작권 없는 무료 사진. 자리에는 `![사진](media:아이디)` 한 줄만.
- 태그: 뽑아 둔 12개 그대로, `#` 없이.
- **먼저 비공개로 올린다.** 사용자가 보고 괜찮다고 하면 공개로 바꾼다 (사용자가 처음부터 공개를 명시했으면 공개).
- 올라가면 글 주소를 알려준다.

## 막히면

먼저 확장이 켜져 있는지, 대기 중인 글이 있는지 uplika로 확인한다.

| uplika가 전한 말 · 증상 | 할 일 |
|---|---|
| 확장이 꺼져 있어 대기 중 | 컴퓨터 크롬 켜기 (최대 7일 대기, 켜면 1분쯤 뒤 발행) |
| 네이버 로그인이 필요 | 그 크롬에서 네이버 로그인 |
| 폼을 먼저 고르라며 멈춤 | 5단계 "구조 그대로" 조건 지키기 |
| 엉뚱한 게시판에 올라감 | 카테고리 이름 명시 |
| 방금 만든 카테고리가 안 보임 | 블로그 카테고리 다시 읽기 |
| 발행이 잠시 제한 | 바로 재시도하지 말 것 (하루에 몰아 올리지 않기) |
| 확장 버전이 낮다 | 확장 업데이트 |
| 사진 자리에 글자가 보임 | 사진 줄을 한 줄로 |

## 원칙

주 3~5편, 원본 사진, 같은 글 재탕 금지. 하루에 여러 편 몰아 올리지 않는다.
