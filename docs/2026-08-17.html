NASA Saves an Old Space Telescope

모르는 단어를 누르면 뜻이 나와요

In 2004, NASA sent a special telescope named Swift into space. It looks at very bright flashes of light. These lights help scientists learn how the universe changes.

Now, there is a big problem. Swift is slowly falling down. It is getting too close to Earth. If it falls into the air around Earth, it will burn up. NASA wants to save this old telescope.

To save it, NASA sent a robot spaceship named LINK. LINK will fly up and meet Swift. It will use three long arms to grab the telescope. Then, LINK will slowly push Swift up to a higher, safer place.

After pushing Swift, LINK will let go. The robot spaceship will fall and burn up. But Swift will be safe! This rescue is very hard. The old telescope is weak and might break easily. Engineers must be careful.

If the robot does a good job, Swift can work for five more years. NASA will save a lot of money. They will not have to build a new telescope. This is a great way to fix old things in space!
