자음 + 모음 + 받침 접기 카드 📥 기본 세트 PDF 🃏 낱말 그림 카드 (양면) 아래에서 고른 카드가 A4 가로 시트에 담겨요. 인쇄 설정은 A4 · 가로 · 실제 크기 100%. 아이폰은 열린 PDF에서 공유 → '파일에 저장'.

➕ 칸을 뒤로 접으면, 글자가 돼요 카드를 눌러 보세요

1. 실선 따라 자르기

카드 바깥 굵은 실선만 가위로 잘라요. 안쪽 점선은 자르지 않아요.

2. ➕ 칸 가운데를 잡고 뒤로 반 접기

➕ 칸이 뒤로 숨으면 파란 자음과 빨간 모음이 딱 붙어요. 양쪽 점선이 저절로 접혀요.

3. 펼쳤다 접었다, 소리 내 읽기

펼치면 "그… 아…", 접으면 "가!" 자음 소리와 모음 소리가 합쳐지는 걸 눈으로 봐요.

4. 초록 받침은 날개로

ㅏㅓㅣ 글자(감·산·집)는 자음 아래 초록 받침 날개가 있어요. ➕ 칸·모음 아래 실선은 잘라서 떼고, 자음 아래 점선으로만 접혀요. 뒤로 숨기면 "가", 내리면 "감"!

5. ㅗㅜㅡ 글자는 세로로 두 번

곰·눈·물처럼 모음이 아래에 오는 글자는 자음·➕·모음·➕·받침이 세로로 쌓여요. ➕ 칸 두 개를 차례로 뒤로 접어요.

파랑 = 자음(첫소리)빨강 = 모음초록 = 받침(끝소리)점선 = 접는 선실선 = 자르는 선
