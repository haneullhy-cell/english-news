자음 + 모음 접기 카드 📥 기본 세트 PDF 아래에서 고른 카드가 A4 가로 시트에 담겨요. 인쇄 설정은 A4 · 가로 · 실제 크기 100%. 아이폰은 열린 PDF에서 공유 → '파일에 저장'.

➕ 칸을 뒤로 접으면, 글자가 돼요 카드를 눌러 보세요

1. 실선 따라 자르기

카드 바깥 굵은 실선만 가위로 잘라요. 안쪽 점선은 자르지 않아요.

2. ➕ 칸 가운데를 잡고 뒤로 반 접기

➕ 칸이 뒤로 숨으면 파란 자음과 빨간 모음이 딱 붙어요. 양쪽 점선이 저절로 접혀요.

3. 펼쳤다 접었다, 소리 내 읽기

펼치면 "그… 아…", 접으면 "가!" 자음 소리와 모음 소리가 합쳐지는 걸 눈으로 봐요.

파랑 = 자음(첫소리)빨강 = 모음점선 = 접는 선
