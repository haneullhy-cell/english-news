공공데이터 API 찾기

공공데이터포털 오픈 API …개를 한곳에서 검색해요.

처음이라면: 인증키 받는 법
  1. 공공데이터포털(data.go.kr)에 회원가입하고 로그인해요.
  2. 여기서 쓸 API를 찾아 이름을 누르면 포털의 API 페이지가 열려요. 활용신청 버튼을 눌러요.
  3. 운영 자동승인 표시가 있으면 신청 즉시 쓸 수 있고, 운영 심의는 실서비스 단계에서 기관 심의를 거쳐요. 개발계정은 대부분 바로 승인돼요.
  4. 포털 마이페이지 › 데이터활용 › Open API에서 인증키(serviceKey)를 확인해 요청 주소에 붙여 써요.
  5. 상업 서비스에 쓸 거라면 상업 이용 가능만 켜서 찾으세요. 출처표시가 붙은 것은 화면에 출처를 적어야 해요.
  1. 목록을 불러오는 중…
데이터 출처: 공공데이터활용지원센터_공공데이터포털 목록개방현황(공공데이터포털, 매달 갱신). 이 페이지는 그 파일을 자동으로 받아 정리해요.
지역은 제공기관 이름으로 추정한 값이라 틀릴 수 있어요. 활용신청 수는 포털 집계 기준이에요.
공공데이터포털과 관계없는 개인 도구예요. 신청과 이용은 각 API의 포털 페이지에서 하세요.
